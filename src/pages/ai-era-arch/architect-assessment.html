Scenario-based Assessment — 三类核心情景题

场景 A：AI-native SDLC Enterprise Transformation

某大型企业已有 Jira、GitHub、CI/CD、测试平台和传统研发管理体系。企业希望在 6–12 个月内通过 AI Agents 重塑研发全生命周期。请设计转型方案。

  1. Plan / Design：如何将需求、业务意图转化为 intent.md、specification、plan，并实现可追溯？
  2. Build：如何设计 Agentic Coding、Subagents、并行工作流、Agent Skills、Hooks 和 Context Engineering？
  3. Test：如何建立反馈闭环、Continuous Evals、测试数据集、质量门禁？模型、Prompt、Skill、Hook 变化如何回归？
  4. Deploy：如何设计 PR Review、CI/CD 集成、权限隔离、Human Approval、灰度和回滚？
  5. Maintain：如何让生产监控、事件和业务指标触发诊断、生成新 Intent 并进入下一轮改进？
  6. 组织：研发人员、QA、架构师、平台团队、产品经理的职责如何变化？如何培训和管理变革？
  7. 度量：如何定义 Lead / Lag 指标？至少给出交付周期、吞吐量、缺陷逃逸率、返工率、Agent 成功率、人工审核负荷和单位变更成本的基线与目标。

必须深挖的证据

候选人亲自负责的团队/仓库数量、改造前后流程图、Agent 工作流、Skills / Hooks 示例、Evals 数据集、CI 记录、生产发布记录、质量和效率数据、失败案例与回滚机制。

场景 B：Enterprise AI / LLM Architecture

大型企业建设统一 AI Platform，服务多个业务域的 RAG、Agent 和企业知识助手。请画出端到端架构并解释关键决策。

  1. 模型层：Model Selection、Model Routing、大小模型分层、私有化与云 API 的 Build / Buy 权衡。
  2. 知识层：数据接入、权限继承、解析、Chunking、Embedding、Hybrid Search、Reranking、知识更新与删除。
  3. Agent 层：Agent Loop、Tool Calling、MCP / API、Workflow 与自主 Agent 边界、状态和记忆。
  4. Context：上下文构建、压缩、检索、窗口预算、来源溯源和上下文污染防护。
  5. LLMOps：离线/在线评测、数据集、Prompt / Model / Agent 版本、Tracing、质量回归。
  6. 安全：身份透传、租户隔离、行/文档级权限、Prompt Injection、工具最小权限、Sandbox、审批和审计。
  7. 非功能：吞吐、延迟、可用性、成本、缓存、降级、灾备和供应商切换。

必须深挖的证据

生产架构图、RAG 评测集、检索质量指标、模型路由策略、Agent Trace、权限测试、成本报表、SLO、故障复盘和安全威胁模型。

场景 C：AI-driven Business Transformation

客户高管提出“全面引入 AI”，但没有明确业务价值和实施路线。请从咨询到规模化落地设计完整方案。

  1. 如何通过访谈、流程挖掘、价值链分析识别高价值 Use Cases？如何避免从技术找场景？
  2. 如何量化价值：收入增长、成本节约、周期缩短、风险降低、体验提升？基线由谁确认？
  3. 如何设计 PoC / MVP 的假设、数据、成功标准、退出条件和时间盒？
  4. 如何选择 Build / Buy / Partner，考虑差异化、数据敏感度、锁定风险和总拥有成本？
  5. 如何设计目标架构、平台复用、业务域自治和 6–18 个月路线图？
  6. 如何建立 AI Governance、风险分级、审批责任、模型/数据清单和审计？
  7. 如何推动组织、岗位、流程和激励机制改变？如何验证真实 ROI 并规模化推广？

必须深挖的证据

业务案例、价值树、基线与实际结果、投资决策材料、MVP 验收标准、Build/Buy 分析、推广计划、采用率和财务/运营 KPI。
